Kebijakan Privasi KameraBidik

Pembaruan 9 November 2026

KameraBidik adalah aplikasi dokumentasi lapangan dan estimasi ukuran yang dikembangkan oleh Adnan Studio. Aplikasi tidak memerlukan akun KameraBidik.

Kamera, mikrofon, dan lokasi

Kamera digunakan untuk pratinjau, foto, video, dan pengukuran AR. Mikrofon digunakan ketika Anda mengaktifkan audio untuk video. Izin lokasi memungkinkan aplikasi menampilkan koordinat, akurasi, elevasi, kecepatan, nama wilayah, peta, dan cuaca. KameraBidik meminta pembaruan lokasi saat layarnya aktif. Anda dapat mengelola izin di pengaturan Android.

Permintaan ke layanan lain

  • Nama wilayah dicari melalui layanan Geocoder Android. Layanan pada perangkat dapat mengirim koordinat ke penyedia geocoding.
  • Saat inset peta aktif, KameraBidik meminta ubin yang mewakili area GPS dari OpenStreetMap. Permintaan mengungkap area yang diminta dan alamat IP ke layanan tersebut. Privasi OpenStreetMap
  • Saat cuaca aktif, KameraBidik mengirim koordinat yang dibulatkan ke dua desimal ke Open-Meteo untuk estimasi suhu. Penyedia juga menerima informasi koneksi seperti alamat IP. Ketentuan Open-Meteo
  • Mode Bidik memakai Google Play Services for AR dari Google. ARCore memproses data sensor untuk melacak permukaan. Google menjelaskan pengumpulan pengenal pengguna atau perangkat, aktivitas penggunaan API, serta data performa dan diagnostik untuk pengoperasian dan analitik AR. Kebijakan Privasi Google · Pengungkapan data ARCore

Permintaan langsung KameraBidik ke OpenStreetMap dan Open-Meteo menggunakan HTTPS. Penyedia layanan mengelola penyimpanan data mereka sesuai ketentuan masing-masing.

Penyimpanan dan penghapusan

Foto, video, dan foto ukur disimpan di galeri perangkat. KameraBidik tidak mengunggah file media ke server Adnan Studio. Data overlay seperti koordinat atau waktu dapat tercetak permanen pada media. Saat Anda membagikan media, informasi tersebut ikut terlihat oleh penerima.

Hapus file media melalui galeri perangkat. Pengaturan overlay, faktor kalibrasi, dan cache peta disimpan di perangkat. Pengaturan Android dapat digunakan untuk menghapus cache atau data aplikasi. Penghapusan data aplikasi tidak otomatis menghapus file media yang telah disimpan ke galeri.
